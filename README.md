# TP Injection des Dépendances en Java

## 📚 Objectif
Mettre en œuvre le principe de couplage faible à travers des interfaces et l’injection de dépendances.

## 🧱 Architecture
- `IDao`, `DaoImpl`, `DaoImplV2`
- `IMetier`, `MetierImpl`
- Présentations : 
  - `Presentation1.java` : injection statique
  - `Presentation2.java` : injection dynamique via réflexion

## 🚀 Étapes réalisées
1. Création des interfaces
2. Implémentations
3. Tests avec injection statique
4. Tests avec injection dynamique
5. Préparation à l’intégration Spring
